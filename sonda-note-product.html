01 Audio Capture Plasmo · MV3 ↓

Two sources captured and merged via Web Audio API into a single stream. Tab audio uses chrome.tabCapture — captures all participants even when your mic is muted. Critical: In Manifest V3, tabCapture cannot run in the service worker. An offscreen.html document is required to hold the MediaRecorder.

Tab audio
chrome.tabCapture · captures all remote participants · works when mic is muted
Microphone
getUserMedia() · local speaker voice · merged with tab stream via AudioContext
MV3 Offscreen
manifest.json → "offscreen" permission · background.ts creates the document · MediaRecorder lives in offscreen.ts
⚠Zoom and Teams desktop apps are not browser tabs. Tab capture does not work for them. Google Meet only in MVP. Do not promise otherwise.
02 Chunking Strategy 30s MVP · Silero M3 ↓

30-second fixed chunks in Month 1 — WhisperX handles long audio correctly, VAD is not needed yet. Add Silero VAD in Month 3 to chunk on silence boundaries instead of a fixed timer. This alone improves accuracy 20–30% because words stop being cut mid-syllable — especially important for Malayalam where word boundaries carry more meaning.

MVP · 30-second fixed
Zero extra dependency. Simple to implement. WhisperX handles chunk overlap gracefully. Do not over-engineer Month 1.
Month 3 · Silero VAD
Chunks on silence boundaries. Prevents mid-syllable cuts. Malayalam word boundaries preserved. +20–30% accuracy gain.
03 Transport WebSocket · FastAPI ↓

Raw WebM chunks sent over a persistent WebSocket connection to the FastAPI server. The Supabase JWT auth token is attached to every message — this is how the backend knows which workspace to route the recording to. Never do audio conversion in the browser; keep the extension lightweight.

WS /live-transcript → extension to FastAPI · JWT in header · raw WebM payload POST /upload-audio → fallback for completed recordings
04 Audio Conversion ffmpeg · Server-side ↓

Convert on the server — never in the browser. WhisperX requires 16kHz Mono WAV. Doing this server-side keeps the Chrome extension lightweight and the browser responsive during recording.

ffmpeg -i input.webm -ar 16000 -ac 1 -f wav output.wav
05 Speech Recognition WhisperX · Groq → RTX ↓

WhisperX wraps Whisper Large V3 internally and adds word-level timestamp alignment in one step. Do NOT run Whisper and then WhisperX — that transcribes twice and wastes GPU time. Use WhisperX only. Malayalam, Tamil, Telugu, Hindi, and English are all natively supported with auto-detection per chunk.

MVP · Groq API
Free tier. ~$0.02/hr audio. Zero GPU cost. Use until paying users justify infrastructure investment.
Month 6+ · Self-hosted
RTX 4090 (~₹2.5L one-time) or RunPod ($0.74/hr on-demand). Migrate when Groq API costs exceed server cost at your volume.
⚠Do NOT run Whisper + WhisperX sequentially. WhisperX runs Whisper internally. Use WhisperX only or you transcribe every meeting twice.
06 Speaker Diarization NeMo MSDD · Month 3 ↓

NeMo MSDD by NVIDIA. Apache 2.0 — fully commercial safe. Pyannote is non-commercial only; using it would block monetisation. NeMo output is merged with WhisperX word timestamps to produce speaker-attributed lines.

Pyannote 3.1 ✕
Non-commercial license. Best quality but blocks monetisation. Enterprise plan required for commercial use.
NeMo MSDD ✓
Apache 2.0. Commercial-safe. Very good quality. The correct choice.
SpeechBrain
MIT license. Good quality. Use as fallback if NeMo has issues.

07 Transcript Cleaner Your Moat ↓

The component that makes Sonda Note different. Fireflies gives every user the same generic model. You give each workspace a personalised correction layer that improves permanently with every user edit. Three sub-systems work together.

Workspace Vocabulary
Per-company dictionary. Sonda Note, Supabase, Figma, Razorpay. Every correction the user makes is saved and applied to all future meetings in that workspace.
Industry Dictionary
Tech · Business · Real estate · Legal. Loaded based on workspace category. A real estate firm and a software agency have completely different vocabulary.
Manglish Normaliser
IndicXlit · Month 4. cheytho → ചെയ്തോ. Keep code-mixed output — more natural UX for Kerala tech meetings than forcing full native script.
08 Embeddings + Search BGE-M3 · pgvector ↓

BGE-M3 handles multilingual and code-mixed text better than E5-Large for Indic languages. Stored in pgvector — no extra infrastructure. Chunk by speaker turn, not fixed token count, so queries like "what did the client say about pricing?" return accurate, contextual answers.

chunk = { speaker, start_time, end_time, meeting_id, workspace_id, text } // overlap: include last sentence of previous turn in each chunk
09 Meeting Intelligence Templates · Gemini → Qwen ↓

Same transcript, different LLM prompt, dramatically better output. Meeting templates improve results more than any ASR accuracy gain. Gemini 1.5 Flash for MVP (1M context window handles long meetings), Qwen 3 32B self-hosted at Month 6+ to eliminate per-token API costs.

Avoid these traps

What not to build.

Six decisions that look like progress and are not. Every founder before you made at least two of these.

✕
Real-time live captions in Month 1
Adds WebSocket complexity, GPU spikes, streaming failures. Post-processing is 10× simpler. Fireflies launched post-processing only — so can you.
✕
Custom ASR training / LoRA fine-tuning
Takes 3–6 months. Whisper Large V3 with a good vocabulary dictionary beats a mediocre fine-tuned model. Build the product first.
✕
Pyannote for diarization
Non-commercial license. Blocks monetisation. NeMo MSDD is Apache 2.0, commercially safe, and nearly as good.
✕
Zoom desktop support in MVP
Desktop app ≠ browser tab. Tab capture won't work. Needs system audio capture via Tauri or Electron. Build after Google Meet works and users ask for it.
✕
Teams enterprise support
Microsoft blocks third-party recording for enterprise accounts via admin policy. Not a technical problem you can solve.
✕
Datasets for training
OpenSLR 63, IndicVoices, AMI, Synth-Manglish — for benchmarking accuracy and mining vocabulary only. The moment you start writing training code, you've lost months.
